## Подробный контекст

План и фактический объём совпадают: обработка Escape, русские кнопки редактора, целевые тесты, независимый аудит, обновление README и TODO-003. Реальная проверка интерфейса остаётся отдельным шагом.

В `src/course_reader/window.py` метод `escape_target` выбирает одну панель: при фокусе внутри заметок — заметки, иначе сначала поиск, затем заметки. `eventFilter` обрабатывает Escape без модификаторов для виджетов главного окна, не вмешивается в активные модальные диалоги, всплывающие меню и чужие окна. Автоповтор не вызывает повторное закрытие. Фильтр регистрируется в приложении и удаляется при закрытии окна. `hide_find` снимает подсветку и возвращает фокус просмотрщику; закрытие заметок также возвращает фокус странице.

`note_text_dialog` использует многострочный QInputDialog с кнопками «Добавить»/«Сохранить» и «Отмена». `add_note` и `edit_note` изменяют данные только после подтверждения непустого текста; отмена оставляет данные и панель заметок без изменений.
