Значимые файлы и области:

- `src/course_reader/window.py`: создание `notes_search`, очистка запроса в `open_course`, фильтрация в `refresh_notes`. Сравнивается подстрока текста через `strip().casefold()` для запроса и `casefold()` для текста заметки. Фильтрация не меняет записи хранения.
- `refresh_notes`, `selected_note`, `update_note_actions`: выбор связывается с `(root, page, id)`, сохраняется только для видимого результата; скрытый или устаревший выбор запрещает изменение, удаление и открытие страницы.
