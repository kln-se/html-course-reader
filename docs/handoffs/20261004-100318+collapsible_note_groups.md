## Подробный контекст

- `src/course_reader/window.py`: заголовки QListWidget теперь включены, но не выбираются как заметки. `NOTE_GROUP_ROLE` хранит курс и путь; `toggle_note_group` скрывает строки выбранной группы без перестройки списка. `update_note_group_icons` обновляет тематические шевроны. `src/course_reader/theme.py` содержит новый SVG `chevron_down`.
- `collapsed_note_groups` и `note_groups` живут только в памяти активного курса. Переходы между страницами и закрытие панели сохраняют состояние; смена/удаление курса сбрасывают его до очистки запроса поиска. В JSON состояние групп не записывается.
- Поиск временно раскрывает результаты и игнорирует клики по заголовкам. Очистка запроса возвращает сохранённое сворачивание. Выбор скрытой заметки сбрасывается, действия над ней отключаются. Общий счётчик курса не зависит от сворачивания и поиска.
- Успешное добавление раскрывает только группу открытой страницы; фильтр поиска продолжает действовать. Отмена и пустой текст не меняют группы. Формат истории и сами материалы курса не изменены.
