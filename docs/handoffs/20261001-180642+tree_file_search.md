## Подробный контекст

### Поведение и значимые файлы

В src/course_reader/window.py добавлены строка поиска, кнопка лупы после прицела
и сообщение «Ничего не найдено». show_tree_search передаёт фокус строке;
filter_tree ищет подстроку относительного пути через casefold, убирает пробелы
по краям и нормализует разделители. Родители совпадений остаются видимыми
и раскрываются. Фильтр форматов сохраняется, список файлов навигации
не ограничивается запросом.

При очистке возвращается прежнее раскрытие папок, после чего раскрывается
путь к текущей странице, восстанавливаются выделение и прокрутка к ней,
если файл есть в дереве. HTML не перезагружается. hide_tree_search очищает
запрос, скрывает строку и возвращает фокус дереву. focus_current_page очищает
запрос перед показом текущего файла. set_course сбрасывает и закрывает поиск;
перестроение каталога повторно применяет сохранённый запрос.

escape_target сохраняет приоритет заметок при фокусе внутри них. При фокусе
в дереве или строке поиска закрывается поиск файлов. В остальных случаях
порядок: поиск по странице, заметки, поиск файлов. Модальные диалоги
и всплывающие меню обрабатывают Escape самостоятельно.

Тесты: новый tests/test_tree_search.py; адаптированы tests/test_active_course.py,
tests/test_catalog_refresh.py и tests/test_escape.py. README описывает
пользовательское поведение и пределы проверки. TODO-005 содержит согласованные
требования вместо прежних открытых вопросов о навигации.
