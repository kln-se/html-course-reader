## Подробный контекст

INI хранит `[files.pages]`, `[files.video]`, `[files.other]` с `patterns` и `enabled`; по умолчанию включены страницы. Старое `[app] visible_patterns` мигрирует только при отсутствии всех новых секций. Известные точные маски страниц и видео распознаются без учёта регистра, прочие выражения попадают в other. Группы с перенесёнными масками включаются, остальные получают стандартные списки и остаются выключенными; пустое старое поле выключает все группы. При наличии любой новой секции старое поле не участвует, отсутствующие группы и параметры дополняются стандартными значениями. Инициализация меняет только память; обычное сохранение записывает новый формат без старого поля.

Видимость определяется объединением масок включённых групп, без взаимного исключения: широкий шаблон в другой группе может показывать формат выключенной группы. Группы не задают способ открытия: встроенный просмотр остаётся для HTML/HTM/MHTML/MHT, остальные форматы открываются внешним приложением после подтверждения.
