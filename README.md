# Course Reader

Desktop-приложение для Windows на Python и PySide6: дерево локального курса слева, сохранённая страница в Qt WebEngine справа. Файлы курса приложение не изменяет. Избранное, заметки и место чтения хранятся отдельно.

## Запуск и состояние проверки

Проверенное окружение проекта: Python 3.13.3, PySide6 6.11.1, pytest 9.1.1. PySide6 закреплён в `requirements.txt`; pytest нужен для разработки и тестов.

Из корня проекта с подготовленным окружением:

```powershell
.\.venv\Scripts\python.exe -B main.py
```

## Чтение курса

При запуске автоматически открывается последний активный курс и его существующий последний файл. Если активный курс ещё не выбран или его папка недоступна, показывается выбор курса. Для истории старой версии нужно один раз выбрать курс. Кнопка «Курсы» позволяет переключиться на другой курс; выбор открывается кнопкой «Открыть» или двойным щелчком.

«Добавить папку» выбирает новый корень, «Указать новое расположение» связывает прежнюю историю с другой папкой без перемещения материалов. Если последняя страница отсутствует или курс новый, область чтения остаётся пустой: первая страница автоматически не открывается.

Во вкладке «Файлы» слева над деревом расположены компактные кнопки 30×30 логических пикселей с SVG-пиктограммами: «Свернуть всё» — стрелки внутрь (`><`), «Развернуть всё» — наружу (`<>`), «Показать текущую страницу в дереве» — мишень, «Найти файл» — лупа. Третья кнопка очищает поисковый запрос, раскрывает родительские папки открытого файла, выделяет его строку, прокручивает дерево к ней и передаёт дереву фокус без повторной загрузки страницы. Кнопка недоступна, если страница не открыта или её строки нет в дереве: например, после исключения формата фильтром либо обновления каталога после удаления файла. Их подсказки и доступные имена заданы на русском. Перед именем файла показано его последнее расширение в нижнем регистре: `[.html] 01.HTML`, `[.gz] archive.tar.GZ`. Исходное имя сохраняется; файлы без расширения и папки показаны без префикса. Подписи не меняют пути и порядок сортировки. Папки выделены Bold (700), префиксы расширений — Semibold (600), имена файлов — обычным начертанием (400). При нехватке ширины имя файла сокращается в середине только при отрисовке; полная подпись и путь сохраняются. Цвет выделенного текста соответствует текущей теме. Всплывающая подсказка содержит полный относительный путь.

«Найти файл» открывает строку под кнопками и передаёт ей фокус. Поиск сразу фильтрует дерево по подстроке относительного пути, включая имя файла, без учёта регистра. Пробелы по краям запроса игнорируются, разделители `/` и `\` равнозначны. Родительские папки совпадений остаются видимыми и раскрываются; при отсутствии совпадений появляется «Ничего не найдено». Фильтр групп форматов продолжает действовать. Очистка запроса возвращает дерево и прежнее раскрытие папок, затем раскрывает путь к текущей странице, выделяет её и прокручивает дерево к ней, если файл присутствует в дереве. Страница при этом не перезагружается. При смене курса строка закрывается и запрос сбрасывается; обновление каталога сохраняет и повторно применяет запрос.

Один щелчок по файлу в дереве открывает его. Дерево показывает только совпавшие с масками файлы и необходимые для них папки. Имена сортируются естественно: `2` перед `10`. Символические ссылки и недоступные для перечисления папки пропускаются. Сканирование синхронное: большой курс может задержать интерфейс.

«Назад» и «Вперёд» переходят по полному списку страниц, допущенных фильтром форматов, в порядке рекурсивного обхода, включая соседние папки. Поисковый запрос в дереве этот список не ограничивает. Посторонние форматы пропускаются; на границе появляется сообщение. Последний файл может открыться из истории даже после исключения его расширения из фильтра — в дереве он тогда не выделяется.

ПКМ в области страницы открывает русское меню: «Предыдущая страница», «Следующая страница», «Копировать», «Выделить всё», «Найти на странице». Переходы повторяют навигацию кнопок по порядку файлов курса и сообщения на границах. Навигация доступна при выбранном курсе, копирование — при выделении текста, выделение всего и поиск — при открытой странице. Стандартных пунктов сохранения страницы и просмотра исходного кода в меню нет.

Встроенному просмотрщику передаются `.html`, `.htm`, `.mhtml`, `.mht`. Пользователь подтвердил отображение проверочного MHTML; совместимость с произвольными архивами MHTML/MHT не гарантируется. Для других видимых файлов приложение запрашивает подтверждение открытия через ассоциацию Windows: например, MP4 откроется в VLC, если он назначен по умолчанию. Диалог содержит русские кнопки «Открыть» и «Отмена»; по умолчанию выбрана «Отмена», Escape также отменяет открытие.

Строка состояния показывает имя корня и относительный путь страницы. `Ctrl+F` открывает поиск по текущей странице, Enter повторяет поиск. Escape без модификаторов закрывает одну панель: при фокусе внутри заметок — заметки; при фокусе в дереве или строке поиска файлов — поиск файлов, если он открыт. В остальных случаях приоритет имеют поиск по странице, затем заметки, затем поиск файлов. Закрытие поиска файлов очищает запрос и возвращает фокус дереву; закрытие других панелей возвращает фокус странице, а закрытие поиска по странице также снимает подсветку. Удержание Escape не закрывает следующую панель автоматически. Активный диалог или всплывающее меню обрабатывает Escape самостоятельно. Кнопки масштаба и `Ctrl+-` / `Ctrl+=` меняют масштаб всей страницы в диапазоне 25–300%, а не только текста. Вертикальная прокрутка HTML/HTM восстанавливается при открытии через дерево, избранное, кнопки навигации и историю курса. При переходе по ссылке приложение не подставляет сохранённую позицию: якорь и начальное положение обрабатывает движок. Для MHTML/MHT восстановление прокрутки отключено, поскольку движок ограничивает выполнение JavaScript в архиве; его защитные настройки не ослабляются.

## Избранное и заметки

Кнопка «Избранное» с пиктограммой закладки переключает отметку текущей страницы. Вкладка «Избранное» принадлежит выбранному курсу; щелчок открывает страницу. Записи не удаляются автоматически при исчезновении файла.

«Заметки (N)» показывает или скрывает панель всех заметок выбранного курса; N — их общее количество. Записи сгруппированы по относительным путям страниц. В заголовке каждой группы указано число заметок, у каждой записи — «Изменено:» и дата последнего изменения в локальном часовом поясе и кратком формате системы. В истории дата сохраняется в UTC без изменения формата; дата без смещения трактуется как UTC, некорректная отображается как «неизвестно». Заголовки неинтерактивны. При каждом открытии панели выбор заметки сбрасывается; если страница открыта, фокус получает кнопка добавления.

Сверху панели постоянно доступна строка «Найти заметку…». Она сразу фильтрует заметки всего выбранного курса по подстроке текста: можно ввести слово или фразу, регистр и пробелы по краям запроса игнорируются. Имена страниц и даты в поиске не участвуют. Группы без совпадений скрываются; заголовки оставшихся групп показывают количество совпавших заметок, а кнопка «Заметки (N)» сохраняет общее количество заметок курса. Если совпадений нет, показано «Ничего не найдено». Очистка строки возвращает полный список; при смене курса запрос сбрасывается.

При фильтрации выбор сохраняется, пока выбранная заметка остаётся в результатах. Если она скрыта или больше не существует, действия с ней недоступны. Добавление остаётся привязанным к открытой странице; после добавления, изменения или удаления текущий запрос применяется повторно. Escape при фокусе в строке поиска заметок закрывает панель по общему правилу Escape.

«Добавить к открытой странице» создаёт заметку для открытой страницы независимо от выделения в дереве и списке заметок. Над кнопкой показан относительный путь открытой страницы. Если страница не открыта, показано «Нет открытой страницы», а добавление недоступно. «Изменить» и «Удалить» работают с выбранной заметкой, даже если в просмотрщике открыта другая страница. В многострочном редакторе кнопка подтверждения называется «Добавить» или «Сохранить», кнопка отмены — «Отмена». Escape отменяет ввод без изменения заметки и закрытия панели за диалогом. Подтверждение удаления содержит кнопки «Удалить» и «Отмена»; по умолчанию выбрана «Отмена», Escape и закрытие диалога также отменяют удаление. Без выбранной заметки эти действия и «Открыть страницу» недоступны.

«Открыть страницу» или двойной щелчок по заметке открывает связанную страницу. Если файл отсутствует, приложение сообщает об этом, а заметка сохраняется в списке. Заметки содержат обычный текст; пустые и состоящие из пробелов записи не сохраняются. Привязки к элементам HTML нет. Формат хранения заметок в истории не изменился.

## Настройки

В режиме исходников `settings.ini` и `history.json` хранятся в корне проекта. В упакованном запуске используется папка исполняемого файла. Она должна быть доступна для записи. Отсутствующие файлы создаются при сохранении; автоматического переноса в профиль Windows нет.

Пример `settings.ini` в UTF-8 со значениями по умолчанию:

```ini
[app]
internet_links = false
theme = dark
zoom = 1.0

[files.pages]
patterns = *.html, *.htm, *.mhtml, *.mht
enabled = true

[files.video]
patterns = *.mp4, *.m4v, *.mpeg, *.mpg, *.avi, *.mkv, *.webm, *.mov
enabled = false

[files.other]
patterns = *.pdf, *.txt
enabled = false
```

| Параметр | Контракт |
| --- | --- |
| `files.pages`, `files.video`, `files.other` | Группы «Страницы», «Видео» и «Другие файлы». В каждой `patterns` хранит маски имён через запятую без учёта регистра, `enabled` включает их в фильтр дерева. По умолчанию включены только страницы. |
| `internet_links` | `false` по умолчанию: интернет-переход игнорируется. При `true` открытие во внешнем браузере требует подтверждения. |
| `theme` | `dark` — графитовая тема по умолчанию, `light` — светлая. Оформление HTML не меняется. |
| `zoom` | Число от `0.25` до `3.0`; по умолчанию `1.0`. |

В диалоге настроек каждой группе соответствует строка с флажком «Показывать» и редактируемым списком масок. Отключение группы сохраняет список; редактировать его можно и при снятом флажке. «Применить» сохраняет настройки, применяет тему и перестраивает дерево. «Отмена» закрывает диалог без переноса введённых изменений в настройки и без записи. Масштаб меняется на панели чтения.

Фильтр объединяет непустые маски всех включённых групп. Выключенные группы не исключают файлы, совпавшие с масками другой включённой группы: например, `*.*` в «Других файлах» может показывать и видео. Пустой список не добавляет файлов; если включённых непустых масок нет, дерево пусто. Добавление маски или перенос её в группу «Страницы» не добавляет встроенный просмотр формата.

Старое поле `[app] visible_patterns` автоматически переносится при запуске, если ни одной секции `files.pages`, `files.video`, `files.other` ещё нет. Точные известные маски страниц и видео распределяются по этим группам без учёта регистра; остальные маски, включая пользовательские wildcard-выражения, попадают в «Другие файлы». Группы с перенесёнными масками включаются. Остальные получают стандартные списки, но остаются выключенными: исходная видимость сохраняется, а пустое старое поле выключает все группы. При наличии хотя бы одной новой секции старое поле игнорируется; недостающие группы и параметры получают значения по умолчанию. Подготовка настроек происходит в памяти, новый формат без старого поля записывается только при обычном сохранении.

Для ручного редактирования INI закройте приложение: настройки читаются при запуске, а работающее приложение может перезаписать внешний файл своими значениями. Некорректный формат или неподдерживаемые значения могут остановить запуск с сообщением об ошибке.

## Ссылки и локальные ресурсы

Существующая локальная страница внутри выбранного корня открывается в текущем просмотрщике. Интернет-адрес не сопоставляется автоматически с сохранённой копией. Локальные переходы главной страницы за пределы корня отклоняются. Неподдерживаемый локальный формат предлагается открыть внешним приложением.

Перехватчик WebEngine блокирует схемы запросов, кроме `file`, `data`, `blob`, `qrc` и `about`; локальным страницам также отключён доступ к удалённым URL через соответствующую настройку Qt. Это ограничение запросов не является гарантией полной сетевой или файловой изоляции недоверенного HTML. В частности, проверка корня для переходов не представляет собой общий запрет чтения всех локальных ресурсов страницей.

JavaScript страницы остаётся доступным: локальные раскрывающиеся элементы могут работать, если их код и ресурсы сохранены. Серверные функции, отсутствующие изображения, скрипты или стили приложение не восстанавливает. Разрешение интернет-ссылок относится к открытию браузера, а не к разрешению удалённых ресурсов внутри страницы.

## Хранение и перенос

`history.json` содержит словарь `courses`, где ключ — абсолютный путь корня. У каждого курса есть `last` (последняя страница), `scroll` (вертикальные позиции), `favorites` (список страниц) и `notes` (списки заметок по страницам). Пути страниц относительны корню. Заметка хранит `id`, `text`, `created` и `updated`. Необязательное поле верхнего уровня `active_course` хранит абсолютный корень активного курса; при смене его расположения ссылка обновляется. Отсутствующее или пустое значение, а также ссылка на курс вне `courses` означают, что при запуске потребуется выбор курса.

Для переноса сохраните оба файла данных и сами материалы курса. Если корень изменился, укажите новое расположение в выборе курса. Переименование отдельных страниц автоматически не отслеживается; заметки и избранное остаются привязаны к старым относительным путям. Нельзя заменить корень на папку, уже представленную другой записью истории.

Каждый файл данных записывается через временный файл с последующей заменой. Совместной транзакции для INI и JSON нет: ошибка второй записи не отменяет первую. При ошибке сохранения показывается предупреждение; закрытие окна всё равно допускается. Одновременная работа нескольких экземпляров с общими данными не согласуется блокировкой. Перед ручным редактированием или переносом рекомендуется сохранить копию файлов данных.

## Устройство и тесты

| Модуль | Ответственность |
| --- | --- |
| `main.py`, `src.course_reader.__main__` | Запуск Qt, расположение данных и сообщение об ошибке инициализации. |
| `src.course_reader.catalog` | Маски, естественный порядок, обход, соседняя страница и классификация адресов. |
| `src.course_reader.storage` | Проверка и сохранение настроек, история, избранное и заметки. Изменения состояния сохраняются явным вызовом `save()`. |
| `src.course_reader.viewer` | Политика запросов и переходов WebEngine, сигналы для главного окна. |
| `src.course_reader.window` | Выбор курса, панели, обработка пользовательских действий и сохранение состояния. |

Запуск согласованных unit-тестов логики:

```powershell
.\.venv\Scripts\python.exe -B -m pytest -p no:cacheprovider tests
```

Тесты используют временные каталоги для сценариев хранения и обхода. Их успешное выполнение не заменяет отдельную проверку рендера, диалогов, восстановления прокрутки в WebEngine, ассоциаций Windows и portable-поставки.

## Оформление интерфейса

Основной шрифт — установленный Segoe UI Variable Text или Segoe UI; пути используют Cascadia Mono или Consolas с системным запасным вариантом. Шрифты не загружаются. Палитры и размеры централизованы в `src/course_reader/theme.py`.

Панель инструментов использует векторные пиктограммы для разных плотностей экрана, группы действий и индикатор масштаба. Минимальная высота строки дерева — 32 логических пикселя. Выделение отображается мягким фоном, фокус — полосой у края вместо системной рамки. Пустые списки содержат пояснения, длинные пути доступны в подсказках. Оформление HTML не меняется.

Ориентиры: [Microsoft Typography](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/typography) и [Microsoft Layout](https://learn.microsoft.com/en-us/windows/win32/uxguide/vis-layout). Пользователь подтвердил оформление обеих тем на своём компьютере; проверка разных масштабов Windows отдельно не выполнялась.

## Проводник и обновление каталога

ПКМ по файлу или видимой папке дерева → «Показать в проводнике»: выбранный объект выделяется в родительской папке — одинаково для файлов и директорий. При исчезновении объекта отображается сообщение. Материалы курса приложение не изменяет.

Изменения папок отслеживаются QFileSystemWatcher, включая пустые папки, чтобы замечать новые вложенные материалы. События объединяются в пределах 250 мс; файлы появляются с учётом масок и естественной сортировки. Обновление сохраняет раскрытие папок, выделение и прокрутку дерева; открытая страница и заметки не перезагружаются. Если файл удалён или переименован, уже отображаемая копия остаётся открытой, а история/заметки автоматически к новому имени не привязываются.

При отказе Qt зарегистрировать наблюдение или исчезновении корня включается резервный опрос раз в 3 секунды. После восстановления наблюдения опрос прекращается. Сканирование синхронное: на очень больших или сетевых курсах возможны задержки. Изменение содержимого уже открытого HTML не вызывает его автоматическую перезагрузку.

## Сборка portable для Windows

Из корня проекта, в окружении с PyInstaller и зависимостями приложения:

```powershell
.\.venv\Scripts\python.exe -B -m PyInstaller --onedir --windowed --name HtmlCourseReader --distpath dist --workpath build --specpath build main.py
```

Это ранее переданная команда ручной сборки; после переноса кода её повторное выполнение и результат ещё не проверены. Точка входа остаётся `main.py`, которая импортирует `src.course_reader.__main__`. Сборщик создаёт промежуточные файлы в `build/`, результат — в `dist/HtmlCourseReader/`. Эти каталоги исключены из Git.

Запуск: `dist/HtmlCourseReader/HtmlCourseReader.exe`. Переносить нужно всю папку `HtmlCourseReader`, включая `_internal`, а не только EXE. Python на целевом компьютере не требуется. Каталог приложения должен быть доступен для записи: рядом с EXE хранятся `settings.ini` и `history.json`. Перед повторной сборкой сохраните копию пользовательских данных существующей поставки. Материалы курсов переносятся отдельно.

Для ручной проверки исходников на искусственном курсе:

```powershell
.\.venv\Scripts\python.exe -B tests/gui_preview.py
```

Этот запуск принудительно открывает искусственный курс и сохраняет проверочные данные в `tests/manual_state/`. Для проверки восстановления активного курса запускайте `main.py`: основной запуск хранит данные в корне проекта, не в `src/`.
