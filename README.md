# HTML Course Reader

Приложение для Windows для чтения локально сохранённых курсов. Дерево файлов и просмотр страницы находятся в одном окне: выберите папку курса и открывайте материалы одним щелчком.

Построено на Python, PySide6 и Qt WebEngine. Поддерживает HTML, HTM и MHTML, не изменяя исходные файлы курса.

## Возможности

- Несколько курсов, восстановление последнего открытого курса и страницы.
- Естественная сортировка файлов, поиск по дереву и переход между страницами.
- Избранное и заметки к страницам с поиском по всему курсу; добавление выделенного текста в заметку.
- Поиск на странице (`Ctrl+F`), масштабирование и сохранение прокрутки HTML/HTM.
- Светлая и графитовая темы интерфейса.
- Группы форматов: страницы, видео и другие файлы. Неподдерживаемые форматы открываются во внешней программе после подтверждения.
- Автоматическое обновление дерева и показ выбранного объекта в Проводнике.
- Раздельные настройки интернет-ссылок и загрузки удалённых изображений, стилей и шрифтов.

## Быстрый старт

После самостоятельной сборки запустите `HtmlCourseReader.exe`, нажмите «Добавить папку» и выберите корневую папку курса. Щёлкните по странице в дереве слева, чтобы начать чтение. Кнопка «Курсы» переключает между добавленными курсами.

Переносите всю папку собранного приложения, включая `_internal`. Установка Python для portable-версии не требуется.

### Запуск из исходников

Требуются Windows и Python 3.13. Выполните из корня репозитория:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -B main.py
```

Если `.venv` уже подготовлена, достаточно последней команды.

## Настройки и данные

Настройки хранятся в `settings.ini`, история чтения, избранное и заметки — в `history.json`. В portable-версии эти файлы находятся рядом с EXE, при запуске из исходников — в корне проекта. Папка приложения должна быть доступна для записи.

Для переноса сохраните оба файла и материалы курсов. Если папка курса переместилась, выберите «Указать новое расположение» в окне выбора курса. Переименование отдельных страниц не переносит их заметки и избранное автоматически.

«Удалить из списка» удаляет историю и заметки выбранного курса из приложения; материалы на диске остаются. Перед ручным редактированием настроек закройте приложение.

## Особенности просмотра

Сохранённая страница может зависеть от отсутствующих файлов или серверных функций. Приложение не восстанавливает такие зависимости и не меняет оформление самой страницы.

Интернет-ссылки и удалённые ресурсы управляются отдельно. Разрешение ресурсов распространяется только на выбранные изображения, стили и шрифты, а не на удалённые скрипты и видео. После изменения настройки откройте страницу заново.

Восстановление прокрутки поддерживается для HTML/HTM, но не для MHTML. Изменение масштаба или ширины окна может сместить текст относительно сохранённой позиции.

## Сборка для Windows

Проект публикуется в виде исходного кода. Готовые EXE и библиотеки зависимостей к релизам не прилагаются. Скрипты ниже предназначены для самостоятельной сборки.

Установите зависимости разработки в подготовленную `.venv`:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

Запустите скрипт из корня репозитория.

**PowerShell:**

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

**Git Bash в Windows:**

```bash
bash scripts/build.sh
```

Оба скрипта используют `.venv`, упаковывают значок и ресурсы приложения, копируют MIT-лицензию проекта. Результат — `dist/HtmlCourseReader/HtmlCourseReader.exe`, промежуточные файлы — `build/`. При ошибке скрипт останавливается. Существующая папка результата не перезаписывается автоматически: перед повторной сборкой перенесите её в другое место, сохранив пользовательские данные.

Сборка Windows EXE выполняется на Windows; Bash-скрипт не предназначен для Linux, macOS или WSL.

Скрипт исключает неиспользуемый QML-интерфейс и проверяет, что в результат не попали его плагины и дополнительные модули Qt. При распространении собственной сборки необходимо отдельно соблюдать условия включённых сторонних компонентов.

## Разработка

Установите `requirements-dev.txt` в `.venv` командой из раздела сборки. Активируйте окружение перед работой над проектом. Затем один раз установите Git hooks:

```powershell
python -m pre_commit install
```

Перед коммитом hooks запускают Ruff (проверку и форматирование), mypy и pytest. Локальные проверки используют `python` из активированного окружения. Первый запуск скачивает окружение Ruff. Ruff может исправлять файлы: проверьте diff, добавьте исправления в индекс и повторите проверку.

Проверка всех файлов, отслеживаемых Git:

```powershell
python -m pre_commit run --all-files
```

Новые файлы должны быть добавлены в индекс, чтобы попасть в эту проверку. Обычный `git commit` проверяет подготовленные изменения; mypy и pytest при этом проверяют весь настроенный набор.

Запуск тестов:

```powershell
.\.venv\Scripts\python.exe -B -m pytest -p no:cacheprovider tests
```
