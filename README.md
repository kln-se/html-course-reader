# Course Reader

Desktop-приложение для Windows на Python и PySide6: дерево локального курса слева, сохранённая страница в Qt WebEngine справа. Файлы курса приложение не изменяет. Избранное, заметки и место чтения хранятся отдельно.

## Запуск и состояние проверки

Проверенное окружение проекта: Python 3.13.3, PySide6 6.11.1, pytest 9.1.1. PySide6 закреплён в `requirements.txt`; pytest нужен для разработки и тестов.

Из корня проекта с подготовленным окружением:

```powershell
.\.venv\Scripts\python.exe -B main.py
```

Импорт приложения и проверки логики не подтверждают работу графического интерфейса. Окна, качество отображения HTML/MHTML и взаимодействие с реальными материалами пока не проверены. Portable-сборка ещё не создана; текущая версия запускается из исходников. Папка с EXE и компонентами Qt остаётся следующим этапом.

## Чтение курса

При запуске открывается выбор ранее добавленного курса. «Добавить папку» выбирает новый корень, «Указать новое расположение» связывает прежнюю историю с другой папкой без перемещения материалов. Для курса восстанавливается существующий последний файл; автоматическое открытие первой страницы для нового курса не выполняется.

Один щелчок по файлу в дереве открывает его. Дерево показывает только совпавшие с масками файлы и необходимые для них папки. Имена сортируются естественно: `2` перед `10`. Символические ссылки и недоступные для перечисления папки пропускаются. Сканирование синхронное: большой курс может задержать интерфейс.

«Назад» и «Вперёд» переходят по видимым страницам в порядке рекурсивного обхода, включая соседние папки. Посторонние форматы пропускаются; на границе появляется сообщение. Последний файл может открыться из истории даже после исключения его расширения из фильтра — в дереве он тогда не выделяется.

Встроенному просмотрщику передаются `.html`, `.htm`, `.mhtml`, `.mht`. Фактическую совместимость MHTML/MHT ещё предстоит проверить. Для других видимых файлов приложение запрашивает подтверждение открытия через ассоциацию Windows: например, MP4 откроется в VLC, если он назначен по умолчанию.

Строка состояния показывает имя корня и относительный путь страницы. `Ctrl+F` открывает поиск по текущей странице, Enter повторяет поиск. Кнопки масштаба и `Ctrl+-` / `Ctrl+=` меняют масштаб всей страницы в диапазоне 25–300%, а не только текста. Вертикальная прокрутка HTML/HTM восстанавливается при открытии через дерево, избранное, кнопки навигации и историю курса. При переходе по ссылке приложение не подставляет сохранённую позицию: якорь и начальное положение обрабатывает движок. Для MHTML/MHT восстановление прокрутки отключено, поскольку движок ограничивает выполнение JavaScript в архиве; его защитные настройки не ослабляются.

## Избранное и заметки

Кнопка «☆ Избранное» переключает отметку текущей страницы. Вкладка «Избранное» принадлежит выбранному курсу; щелчок открывает страницу. Записи не удаляются автоматически при исчезновении файла.

«Заметки (N)» показывает или скрывает панель текущей страницы. Заметки содержат обычный текст, поддерживают добавление, изменение и удаление с подтверждением. В списке отображается дата последнего изменения в UTC. Пустые и состоящие из пробелов заметки не сохраняются. Привязки к элементам HTML нет.

## Настройки

В режиме исходников `settings.ini` и `history.json` хранятся в корне проекта. Для будущего упакованного запуска код предусматривает папку исполняемого файла. Она должна быть доступна для записи. Отсутствующие файлы создаются при сохранении; автоматического переноса в профиль Windows нет.

Пример `settings.ini` в UTF-8:

```ini
[app]
visible_patterns = *.html, *.htm, *.mhtml, *.mht, *.txt, *.mp4
internet_links = false
theme = dark
zoom = 1.0
```

| Параметр | Контракт |
| --- | --- |
| `visible_patterns` | Маски имён через запятую, без учёта регистра. По умолчанию только четыре HTML-расширения. Пустое значение скрывает все файлы. Добавление маски не добавляет встроенный просмотр формата. |
| `internet_links` | `false` по умолчанию: интернет-переход игнорируется. При `true` открытие во внешнем браузере требует подтверждения. |
| `theme` | `dark` — графитовая тема по умолчанию, `light` — светлая. Оформление HTML не меняется. |
| `zoom` | Число от `0.25` до `3.0`; по умолчанию `1.0`. |

Диалог настроек меняет фильтры, тему и разрешение интернет-ссылок сразу. Масштаб меняется на панели чтения. Для ручного редактирования INI закройте приложение: настройки читаются при запуске, а работающее приложение может перезаписать внешний файл своими значениями. Некорректный формат или неподдерживаемые значения могут остановить запуск с сообщением об ошибке.

## Ссылки и локальные ресурсы

Существующая локальная страница внутри выбранного корня открывается в текущем просмотрщике. Интернет-адрес не сопоставляется автоматически с сохранённой копией. Локальные переходы главной страницы за пределы корня отклоняются. Неподдерживаемый локальный формат предлагается открыть внешним приложением.

Перехватчик WebEngine блокирует схемы запросов, кроме `file`, `data`, `blob`, `qrc` и `about`; локальным страницам также отключён доступ к удалённым URL через соответствующую настройку Qt. Это ограничение запросов не является гарантией полной сетевой или файловой изоляции недоверенного HTML. В частности, проверка корня для переходов не представляет собой общий запрет чтения всех локальных ресурсов страницей.

JavaScript страницы остаётся доступным: локальные раскрывающиеся элементы могут работать, если их код и ресурсы сохранены. Серверные функции, отсутствующие изображения, скрипты или стили приложение не восстанавливает. Разрешение интернет-ссылок относится к открытию браузера, а не к разрешению удалённых ресурсов внутри страницы.

## Хранение и перенос

`history.json` содержит словарь `courses`, где ключ — абсолютный путь корня. У каждого курса есть `last` (последняя страница), `scroll` (вертикальные позиции), `favorites` (список страниц) и `notes` (списки заметок по страницам). Пути страниц относительны корню. Заметка хранит `id`, `text`, `created` и `updated`.

Для переноса сохраните оба файла данных и сами материалы курса. Если корень изменился, укажите новое расположение в выборе курса. Переименование отдельных страниц автоматически не отслеживается; заметки и избранное остаются привязаны к старым относительным путям. Нельзя заменить корень на папку, уже представленную другой записью истории.

Каждый файл данных записывается через временный файл с последующей заменой. Совместной транзакции для INI и JSON нет: ошибка второй записи не отменяет первую. При ошибке сохранения показывается предупреждение; закрытие окна всё равно допускается. Одновременная работа нескольких экземпляров с общими данными не согласуется блокировкой. Перед ручным редактированием или переносом рекомендуется сохранить копию файлов данных.

## Устройство и тесты

| Модуль | Ответственность |
| --- | --- |
| `main.py`, `course_reader.__main__` | Запуск Qt, расположение данных и сообщение об ошибке инициализации. |
| `course_reader.catalog` | Маски, естественный порядок, обход, соседняя страница и классификация адресов. |
| `course_reader.storage` | Проверка и сохранение настроек, история, избранное и заметки. Изменения состояния сохраняются явным вызовом `save()`. |
| `course_reader.viewer` | Политика запросов и переходов WebEngine, сигналы для главного окна. |
| `course_reader.window` | Выбор курса, панели, обработка пользовательских действий и сохранение состояния. |

Запуск согласованных unit-тестов логики:

```powershell
.\.venv\Scripts\python.exe -B -m pytest -p no:cacheprovider tests
```

Тесты используют временные каталоги для сценариев хранения и обхода. Их успешное выполнение не заменяет отдельную проверку рендера, диалогов, восстановления прокрутки в WebEngine, ассоциаций Windows и portable-поставки.
